# OpenHarness V2.0 provenance archive

This directory is an immutable historical snapshot of the OpenHarness port at commit
`9b2efd795c6aa09f88b0c257d269a9e518da6ae7`. It is retained for license and provenance review only.

The archived JSON is not a live build or release gate. HomeMaster owns the current implementations under
`src/homemaster`, and `upstream-test-mapping.md` records the regression coverage that replaced the deleted
upstream-only test copy. The former live manifest generator was removed with the `src/openharness` package.

## 真实运行中发现并修复的问题

1. SDK client 继承本地 SOCKS proxy 环境变量，缺少 `socksio` 时失败。
   - 修复：构造 SDK client 时显式使用 `httpx.Client(trust_env=False)`。
   - 这样和旧 raw transport、embedding client 的行为保持一致。

2. Anthropic streaming tool-use 参数丢失。
   - 真实 CLI trace 中出现多次 `task_interpreter` 参数为 `{}`。
   - 根因：stream start block 的 `input={}` 覆盖了后续 `input_json_delta`。
   - 修复：`AnthropicTransport.iter_stream_deltas()` 优先使用累积后的 `input_json_delta` JSON。
   - 已添加回归测试。

3. 提交版配置不能包含真实 key。
   - 处理：`config/homemaster.yaml` 与 example 均使用占位符。
   - 配置解析会忽略 `"<your-api-key>"` 占位符。
   - 无真实 key 时 live API 测试按预期跳过，不再误打真实接口导致 401。

## 本轮 CLI Shell UX 修复

- 默认 shell 输出改为面向用户的分类流：
  - `[模型思考]`
  - `[工具调用]`
  - `[工具结果]`
  - `[工具失败]`
  - `[上下文压缩]`
  - `模型回复：...`
- 默认隐藏内部 runtime/transport 事件，例如 `runtime.turn_started`、`transport.request_started`。
- shell 每轮结束不再自动打印 `status` 和 `trace`；改为：
  - `/status` 查看上一轮状态
  - `/events` 查看上一轮 trace 文件路径
- 新增 `/help`，解释 shell 命令含义。
- 新增 `/compact`，输入命令后立即对已有历史触发 manual context compaction，用于测试 compact 流程。
  - 手动 compact 不再受 token 阈值限制。
  - 空会话或没有可压缩旧历史时不会伪造无意义 summary。
  - 命令会写入自己的 trace，`/events` 可查看这次压缩记录。
- shell 启动时导入 `readline`，改善终端输入编辑体验。
- `homemaster.cli` 包改为懒加载 CLI app，保留 `from homemaster.cli import app` 兼容性，同时消除 `python -m homemaster.cli.app` 的 `runpy` warning。

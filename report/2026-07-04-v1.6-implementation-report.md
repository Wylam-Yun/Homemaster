# HomeMaster V1.6 Implementation Report

Date: 2026-07-04

## Scope Completed

- Added unified YAML/Pydantic config with `config/homemaster.yaml` and `config/homemaster.example.yaml`.
- Migrated provider config resolution to `homemaster.config` with environment overrides for Anthropic endpoint, token, and model.
- Deleted obsolete JSON config files:
  - `config/api_config.json`
  - `config/nvidia_api_config.json`
  - `config/homemaster.example.json`
- Reorganized files into V1.6 package boundaries:
  - providers under `src/homemaster/providers/`
  - events under `src/homemaster/events/`
  - prompts as Markdown under `src/homemaster/prompts/`
  - home domain modules under `src/homemaster/domain/`
- Added SDK-backed provider transport layer:
  - `AnthropicTransport`
  - `OpenAIChatTransport`
  - `LLMClient`
  - shared error and JSON utilities
- Updated generic runtime for streaming deltas, thinking/reply/usage events, cumulative usage, compaction events, cancellation handling, and session/task-state snapshots.
- Integrated session persistence into the runtime loop:
  - `trace.jsonl`
  - `messages.jsonl`
  - `session.json`
  - atomic snapshot writes at stable iteration/exit points
- Added Stage 1 compaction behavior:
  - old image stripping with text placeholders
  - per-tool retention for old tool results
  - optional LLM summary call using the compact-summary prompt when a summary-capable client is provided
  - conservative abort behavior when LLM summary fails and `abort_on_summary_failure` is enabled
  - compacted summary end marker
  - final tool-pair sanitization
- Added provider token estimators:
  - MiMo image estimate using pixel count
  - OpenAI chat image estimate fallback
  - MiMo real usage accounting includes `cache_read_input_tokens`
  - `ContextAssembler` now uses provider estimators for image-aware message estimates
- Added session persistence primitives and `TaskStatus.PAUSED`.
- Added CLI persistence UX:
  - `hm run --resume <id>`
  - `hm run --continue`
  - `hm session list/show/delete/clean/export`
  - `hm shell --resume <id>`
- Consolidated context assembly modules into `src/homemaster/agent/context.py` and removed the split compatibility modules.
- Removed legacy provider transport shims and migrated callers/tests to `LLMClient` plus `homemaster.providers.transports.*`.
- Removed legacy config/runtime compatibility wrappers from `homemaster.runtime`, `homemaster.compat`, and old `homemaster.config.*` modules.
- Removed `world_path` from `RuntimeSettings`; it remains an explicit CLI/tool-registry input where needed.
- Updated stale V1.5 tests to the V1.6 YAML/config/provider contracts.

## Live Issues Found And Fixed

1. SDK clients honored local SOCKS proxy environment settings and failed when `socksio` was not installed.
   - Fixed by constructing SDK clients with explicit `httpx.Client(trust_env=False)`.
   - This matches the existing raw `MimoTransport` and embedding client behavior.

2. Anthropic streaming tool-use parsing dropped arguments.
   - Live CLI trace showed repeated `task_interpreter` calls with `{}` arguments.
   - Root cause: stream start block had `input={}`, while actual arguments arrived through `input_json_delta`.
   - Fixed `AnthropicTransport.iter_stream_deltas()` to prefer accumulated `input_json_delta` JSON over empty start input.
   - Added regression test `tests/homemaster/test_provider_transports.py`.
